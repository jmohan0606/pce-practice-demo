Six Months After an Advisor Leaves
Fee discount sharing pauses for six months after the advisor who originally set the discount leaves the firm, then resumes automatically.
Query this compiles to 
account_month where departed_advisor_sid is not null
  and months_since(departed_advisor_to_time) <= 6
  -> suppress FEE_DISCOUNT_GRID_SHARING

    Sharing a Client Fee Discount
    When a client pays more than 10% below the standard fee, the advisor's payout grid moves down one point for every 1% below that threshold. The grid never falls more than 10 points. Managed accounts only, and only where the pricing decision was made on or after 1 Apr 2026.
    Example — 115 bps standard, 100 bps actual is a 13% reduction, so the grid moves down 3 points.
    Query this compiles to 
    account_month where is_managed = true
  and pricing_decision_dt >= '2026-04-01'
compute round((standard_rate_bps - client_rate_bps) / standard_rate_bps * 100)
when value > 10 -> grid_points = min(value - 10, 10)

    Net New Money Award Qualification
    An advisor qualifies for the award once total net new money for the year reaches $4 million.
    Query this compiles to 
    advisor_flow_month where month_id between :from_month and :to_month
compute sum(total_net_flows)
when value >= 4000000 -> qualified = true
